ชุดเว็บไซต์เครื่องมือแผนที่ประเทศไทย (อำเภอ/ตำบลทั้ง 77 จังหวัด)
=================================================================
โครงสร้าง
  index.html                          หน้าแรก
  feedback-config.js                  ตั้งค่าช่องทางรับข้อเสนอแนะ (แก้ไฟล์นี้ไฟล์เดียว)
  map-generator/index.html            โปรแกรมสร้างแผนที่ขอบเขต
  data-map/index.html                 แผนที่ระบายสีตามข้อมูล
  data-report/index.html              รายงานการตรวจสอบข้อมูลตำบล
  data-report/ตำบลที่ต้องตรวจสอบ.csv  รายการที่ต้องตรวจสอบเพิ่มเติม

ตั้งค่าช่องทางรับข้อเสนอแนะ (ทำก่อนอัปโหลด)
  เปิดไฟล์ feedback-config.js ด้วยโปรแกรมแก้ไขข้อความ แล้วใส่
    email  : อีเมลที่ต้องการรับข้อเสนอแนะ
    formUrl: ลิงก์ Google Forms (ถ้ามี)
  ถ้าปล่อยว่างทั้งสองช่อง ปุ่มส่งอีเมลและแบบฟอร์มจะไม่แสดง ผู้ใช้ยังส่งต่อทาง LINE หรือคัดลอกข้อความได้
  ข้อควรระวัง: อีเมลที่ใส่จะมองเห็นได้ในซอร์สโค้ดของเว็บสาธารณะ อาจมีผู้ส่งจดหมายขยะได้

วิธีเผยแพร่เป็นแอปใหม่บน GitHub Pages
  1) แตกไฟล์ zip นี้
  2) สร้างที่เก็บ (repository) ใหม่ชนิด Public ชื่อใหม่ที่ไม่ซ้ำของเดิม เช่น thailand-map-tools
  3) Add file > Upload files แล้วลากทุกอย่างในโฟลเดอร์ site2 มาวาง (ไม่ใช่ตัวโฟลเดอร์) กด Commit changes
  4) Settings > Pages > Deploy from a branch > main > /(root) > Save รอ 1-3 นาที
  5) ลิงก์จะเป็น https://ชื่อบัญชี.github.io/ชื่อที่เก็บ/
  6) ทดสอบ: ตำบลของอุดรธานีต้องมี 156 รายการ อำเภอเมืองอุดรธานี 21 รายการ ทดลองกดบันทึก PNG/SVG และปุ่มแจ้งข้อเสนอแนะ

ฟังก์ชันเลือกพื้นที่ (ฉบับนี้)
  - เลือกหลายจังหวัด/หลายอำเภอได้ มีปุ่ม เลือกทั้งหมด / ไม่เลือกเลย / สลับการเลือก / แสดงเฉพาะที่เลือก และปุ่ม "เฉพาะ" ท้ายแต่ละรายการ
  - ปุ่มจะทำงานกับรายการที่ผ่านการค้นหาอยู่ (พิมพ์ค้นหาก่อนแล้วกดเลือกทั้งหมดเพื่อเลือกเฉพาะที่ตรงกับคำค้น)

ข้อควรทราบ
  - ไฟล์โปรแกรมแต่ละตัวมีขนาดประมาณ 7 MB (บีบอัดแล้วประมาณ 2-3 MB) โหลดครั้งแรกอาจช้าบนมือถือ
  - ข้อมูลขอบเขตย่อรูปที่ความละเอียดประมาณ 100 เมตร ไม่ใช่ข้อมูลทางการ ดูรายละเอียดในหน้ารายงาน
  - ตัวอ่านไฟล์ Excel โหลดจาก cdnjs.cloudflare.com และฟอนต์จาก Google Fonts หากเครือข่ายบล็อก ไฟล์ CSV ยังใช้ได้
  - ข้อมูลที่ผู้ใช้นำเข้าประมวลผลในเครื่องของผู้ใช้ ไม่ถูกส่งไปที่เซิร์ฟเวอร์
  - เครดิตในหน้าเว็บไม่ควรลบออก เพราะใบอนุญาตของข้อมูลกำหนดให้ต้องอ้างอิงแหล่งที่มา
